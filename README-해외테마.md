# 해외(미국) 테마 — 추가된 것

기존 국내 테마보드에 **국내 / 해외 전환 탭**을 붙였습니다.
화면·정렬·중복테마 정리·랭킹 로직은 국내판을 그대로 씁니다.

```
server_us.py                KIS 해외 API 계층 (server.py 의 토큰·레이트리밋 재사용)
export_snapshot_us.py       web/data_us.json 생성 — 테마·시세
export_detail_us.py         web/priv/detail_us.json 생성 — 뉴스·AI 상승사유
themes_us.json              해외 테마 사전 (편집 가능)
fetch_themes_us.py          ARK ETF 구성종목 자동 갱신
web/index.html              국내/해외 전환 버튼 추가
.github/workflows/snapshot_us.yml   미국장 시간대 자동 갱신
web/index.html.bak          수정 전 원본 (문제 생기면 되돌리기용)
```

---

## 먼저 확인할 것

**한국투자증권에서 해외주식 이용신청이 되어 있어야 합니다.**
국내와 같은 앱키·시크릿을 쓰지만, 해외주식은 별도 신청 항목입니다.
KIS Developers → 신청 내역에서 해외주식이 포함돼 있는지 보세요.

---

## 실행

```bash
python3 fetch_themes_us.py            # ARK 테마 갱신 (하루 한 번)
python3 export_snapshot_us.py         # 테마·시세  → web/data_us.json
python3 export_detail_us.py --ai      # 뉴스·상승사유 → web/priv/detail_us.json
```

거래소를 줄이거나 문턱을 조절할 수 있습니다.

```bash
python3 export_snapshot_us.py --excd NAS,NYS --min-value 20
```

배포는 국내와 동일합니다.

```bash
npx wrangler pages deploy --project-name theme-board --branch main --commit-dirty=true
```

## 시세는 실시간입니다

한국투자증권 공식 문서 기준입니다.

> 지연시세 지연시간 : **미국 — 실시간무료(0분지연)** / 홍콩·베트남·중국·일본 — 15분지연

국내판은 스냅샷 방식이지만 **미국은 조회 시점의 실시간 시세**가 들어옵니다.
유료 신청도 필요 없습니다. (유료 신청이 필요한 건 아시아 국가들뿐입니다)

미국 정규장은 한국시간 **밤 22:30~새벽 05:00**(서머타임) / **23:30~06:00**(표준시)입니다.

## 테마는 두 갈래로 만들어집니다

**1. 업종 — 자동**
한국투자증권이 거래소별 업종 분류를 직접 줍니다(해외주식-048/049).
사전을 만들 필요가 없고, 빠지는 종목도 없습니다. 뼈대 역할입니다.

**2. 테마 — `themes_us.json`**
국내판의 `themes.json` 과 같은 역할입니다. 지금 21개가 들어 있습니다.

| | 갱신 | 내용 |
|---|---|---|
| 반도체 · AI데이터센터 · 양자컴퓨팅 · 로봇 · 사이버보안 · 클라우드 · 원자력 · 태양광 · 전기차 · 비만치료제 · 바이오 · 우주방산 · 핀테크 · 가상자산 · 게임 · 빅테크 | **수동** | 이 파일에서 직접 추가·삭제 |
| ARK 혁신 · 자율주행로봇 · 차세대인터넷 · 핀테크 · 우주탐사 | **자동** | `fetch_themes_us.py` 가 매일 갱신 |

ARK 는 운용사가 매일 구성종목 CSV 를 공개합니다. 그래서 **어떤 종목이 테마에
새로 들어오고 빠졌는지가 자동으로 추적됩니다.** 실행하면 이렇게 나옵니다.

```
ARKK   42종목  +TSLA,SPCX,CRCL,TEM…  -PATH,DKNG
```

국내 테마는 사람이 관리해야 하는데, 이쪽은 자동입니다.

> Global X · Invesco · iShares 는 스크립트 접근을 막아둬서 자동화가 안 됩니다.
> 그쪽 테마(BOTZ·LIT·URA 등)를 넣으시려면 `themes_us.json` 에 티커를 직접 적으세요.

### 테마 추가하는 법

```json
{
  "id": "my-theme",
  "name": "내가 만든 테마",
  "cat": "테마",
  "stocks": ["NVDA", "AMD", "AVGO"]
}
```

종목이 **3개 미만이면 표시되지 않습니다.** 거래대금이 `--min-value` 미만이어도 숨겨집니다.

## 국내판과 다른 점

| | 국내 | 해외 |
|---|---|---|
| 거래대금 단위 | 억원 | **백만달러(M$)** |
| 시세 | 스냅샷 | **실시간(0분 지연)** |
| 뉴스 | 네이버 (본문 있음) | KIS 해외뉴스 (**제목만**) |
| AI 상승사유 | 기사 **본문**을 읽음 | 기사 **제목**만 읽음 |
| 재무 | DART | **없음** (화면에서 숨김) |
| 업종 사전 | 네이버 크롤링 | 증권사 API 자동 |

### AI 상승사유 — 국내보다 근거가 약합니다

국내는 기사 본문을 긁어서 읽습니다. 해외는 **한국투자증권이 뉴스 제목만 주고
원문 링크를 주지 않습니다.** 그래서 AI 가 제목만 보고 판단합니다.

이 차이를 화면에 그대로 드러냈습니다.

| | 국내 | 해외 |
|---|---|---|
| 배지 | 초록 `✓ 기사 본문 확인` | 주황 `뉴스 제목 기준` |
| 하단 고지 | "본문 N건을 읽고 정리" | "**제목 N건만** 읽었으므로 국내보다 근거가 약합니다" |

지어낸 근거가 나가지 않도록 게이트를 걸어뒀습니다. AI 가 인용한 제목이 실제
입력에 없으면 그 근거는 버리고, 남는 게 없으면 "근거 부족"으로 냅니다.
"주가 급등" 같은 결과만 적힌 제목도 이유로 쓰지 않도록 지시해 뒀습니다.

**재무는 화면에서 통째로 숨겼습니다.** DART 는 국내 전용이라 빈 칸이 남는 것보다
안 보이는 게 낫습니다. 필요하면 SEC EDGAR 로 붙일 수 있습니다.

## 자동 갱신

`.github/workflows/snapshot_us.yml` 을 넣어뒀습니다.
평일 UTC 13:30~21:00 사이 30분마다 도는데, 서머타임 전환을 양쪽 다 덮는 범위입니다.

GitHub Secrets 는 국내판이 쓰는 것과 같습니다. `CLOUDFLARE_API_TOKEN` 과
`CLOUDFLARE_ACCOUNT_ID` 만 있으면 배포까지 자동으로 갑니다.

**AI 판독은 자동 실행에서 빼놨습니다.** 30분마다 돌면 하루 15회인데, 거기에
AI 까지 붙이면 Claude 요금이 국내판만큼 한 번 더 나갑니다. 지금 설정은 이렇습니다.

| 스케줄 실행 (30분마다) | 시세 · 테마 · **뉴스** |
| 수동 실행 (Actions 탭 → Run workflow) | 위 + **AI 판독** |

AI 를 자동으로 돌리시려면 `snapshot_us.yml` 의 "종목 상세 (AI 판독)" 단계에서
`if:` 줄을 지우면 매번 돕니다. 요금을 보고 결정하세요.

로컬에서는 언제든 붙일 수 있습니다.

```bash
python3 export_detail_us.py --ai --top 60 --min-rate 2
```
