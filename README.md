# 테마보드 — 실데이터 로컬 실행

한국투자증권 OpenAPI(시세·순위) + DART(재무) + 네이버 뉴스 API를 **실제로 호출**해서
거래대금 상위 종목을 테마별로 묶어 보여주는 대시보드입니다.

앞서 보내드린 프로토타입은 샘플 데이터였고, **이건 진짜 데이터로 돕니다.**

---

## 왜 로컬에서 돌려야 하나

한국투자증권 API는 `openapi.koreainvestment.com:9443` 을 씁니다.
클라우드 작업 환경에서는 이 포트와 DART·네이버 도메인이 모두 차단되어 있어
**사장님 맥에서 직접 실행해야** 합니다. 맥에는 파이썬이 기본 설치돼 있으니 바로 됩니다.

---

## 실행 방법 (3단계)

### 1. config.py를 이 폴더에 넣기

`server.py` 와 **같은 폴더**에 `config.py`를 두세요.
(또는 `~/Desktop/kospi_bot/config.py` 에 있어도 자동으로 찾습니다.)

필요한 키는 5개뿐입니다.

```python
KIS_APP_KEY    = "..."
KIS_APP_SECRET = "..."
KIS_ENV        = "real"      # 모의투자면 "vps"
DART_API_KEY   = "..."
NAVER_CLIENT_ID     = "..."
NAVER_CLIENT_SECRET = "..."
```

> 이 스크립트는 config.py를 **import 하지 않고 정규식으로 읽습니다.**
> 지금 사장님 config.py 27번 줄(`Access Key ID = ...`)에 문법 오류가 있는데,
> 그래도 정상 동작합니다. 다만 다른 코드에서 import 하려면 그 줄은 고쳐야 합니다.

### 2. 연결 점검

```bash
cd ~/Desktop/theme-board
python3 server.py --selftest
```

5개 항목(토큰 → 순위 → 현재가 → DART → 뉴스)을 하나씩 찍어줍니다.
어디서 막히는지 바로 보입니다.

### 3. 실행

```bash
python3 server.py
```

브라우저에서 **http://127.0.0.1:8899** 를 엽니다. 30초마다 자동 갱신됩니다.
종료는 터미널에서 `Ctrl+C`.

## 무엇이 실데이터인가

| 항목 | 출처 | 갱신 |
|---|---|---|
| 거래대금 상위 종목·현재가·등락률 | KIS `volume-rank` (FHPST01710) | 25초 캐시 |
| 시가총액·PER·PBR·52주 고가 | KIS `inquire-price` (FHKST01010100) | 상위 40종목만 |
| 매출·영업이익·부채비율·ROE | DART `fnlttSinglAcnt` | 3일 캐시 |
| 뉴스 제목·링크·발행시각 | 네이버 뉴스 검색 API | 10분 캐시 |
| **테마 분류** | **`themes.json` (사람이 만든 사전)** | 파일 수정 시 |

테마 분류만 API가 아닙니다. **테마-종목 매핑은 어느 무료 API에도 없어서**
44개 테마 / 345개 매핑을 시드로 넣어뒀습니다. (기획서 §9-1에서 지적한 그 부분입니다.)

## 테마 사전 손보기 — 이게 서비스의 핵심 자산입니다

실행하면 화면 상단에 이렇게 뜹니다.

> 거래대금 상위 30종목 중 **83%**가 테마에 매칭됐습니다.
> 미분류: 삼양식품, 알테오젠, …

미분류로 뜬 종목을 `themes.json`에 넣으면 다음 갱신부터 잡힙니다.

```json
{
 "id": "food",
 "name": "음식료",
 "cat": "소비",
 "stocks": ["삼양식품", "CJ제일제당", "농심", "오리온"]
}
```

**종목명 기준**으로 매칭합니다(종목코드 안 외워도 됨).
띄어쓰기·점·하이픈은 무시하니 `LS ELECTRIC` 이든 `LSELECTRIC` 이든 잡힙니다.

이 파일을 키워가는 게 곧 서비스를 키우는 일입니다.
커버리지 80%를 목표로 잡으시면 됩니다.

## 화면 구성

**마켓** — 테마 카드. 카드 = 테마 하나, 안에 그 테마 소속 종목.
`거래대금`·`상승 n/m`·시총가중 등락률. 대장주 쏠림이 심하면 동일가중 등락률을 같이 띄웁니다.

**랭킹** — 거래대금 상위 표 + 테마 컬럼 + 상단 쏠림 분포 바.

**종목 클릭** — 급등사유 근거카드(네이버 뉴스에서 계약·수주·실적 키워드로 자동 선별) →
동일 테마 동반상승 맥락 → DART 재무 → 관련 뉴스.
등락률 3% 미만이면 사유를 지어내지 않고 "뚜렷한 신호 없음"으로 출력합니다.

**테마 클릭** — 구성 종목 + **"오늘 조용한 구성 종목"** (거래대금 상위권에 아직 안 들어온 종목 =
순환매 후발주 후보).

## 주의사항

- **첫 실행은 20~40초** 걸립니다. DART 기업코드 10만 건을 받아 캐시합니다(1회만).
- **KIS 토큰은 하루 1회 발급** 제한이 있어 `.cache/kis_token.json`에 저장합니다. 이 파일을 지우지 마세요.
- **장 시작 전(08:00 이전)이나 휴장일**에는 순위 API가 빈 값이나 전일 데이터를 줍니다.
- KIS 호출은 **초당 20건** 제한이라 개별 시세는 상위 40종목만 조회합니다.
- 순위 API는 **모의투자(vps)에서 미지원**입니다. `KIS_ENV="real"` 이어야 합니다.
- `.cache/` 폴더는 지워도 됩니다(재생성됨).

## 필드명이 안 맞을 때

KIS API 응답 필드명은 문서와 실제가 다른 경우가 있습니다.
`--selftest`에서 값이 0이나 빈 값으로 나오면 알려주세요. 응답 원문을 보고 매핑을 고치면 됩니다.
